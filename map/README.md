# Computation Quests map

The Computation Quests overworld: one continent divided into regions, with Cybersecurity on an island off
the west coast. Roads from every region meet in Ethics and Impacts at the center.

| File | What it is |
|---|---|
| `index.html` | Redirects to the site's home page (`/index.html`), which shows this map. |
| `world.png`, `world-data.js` | Generated by `build_world.py`. Do not edit by hand. |
| `build_world.py` | Builds the overworld. Region names, copy, and layout live at the top. |
| `maplib.py` | Shared map engine, also used by region maps such as `areas/data-science/map/`. |

Region maps are close-ups of the overworld: they call `world_terrain()` from `build_world.py`, so
their coastlines, rivers, and borders match. Rebuild region maps after changing the overworld's
land.

## Building

The maps are drawn from the **La Petite Tile Maps** pixel-art pack. The pack is a third-party
asset and is **not** in this repository (it is listed in `.gitignore`). To rebuild a map, put the
pack at `LaPetiteTile_Maps/` in the repo root (or set the `TILES` environment variable to its
folder), install Pillow, and run from the repo root:

```bash
python map/build_world.py
python areas/data-science/map/build_map.py
```

## Viewing

The pages load their data from neighboring files, so serve the repo over HTTP rather than opening
the file directly:

```bash
python -m http.server 8765
```

Then open http://localhost:8765/. After changing `REGIONS`, also run `python tools/build_pages.py`
so the region pages match.
