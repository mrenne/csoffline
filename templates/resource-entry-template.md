# Resource entry template

Copy this block into an area's `resources/links.md` for each external resource.

```markdown
### Resource title

- **Link:** https://...
- **Type:** unplugged activity collection | book | article | video | website | dataset | slide deck | PDF
- **Grade band:** 6-8, 9-12
- **Big ideas:** ...
- **Author / source:** ...
- **License:** CC BY-NC-SA 4.0 (ours) or the external resource's own license
- **Unplugged?** yes (students need no technology) | teacher background only
- **Why it's useful:** One or two sentences.
```
