# Resource entry template

Copy this block into an area's `resources/links.md` for each external resource.

```markdown
### Resource title

- **Link:** https://...
- **Type:** website | GitHub repo | dataset | video | article | tool | slide deck | PDF
- **Grade band:** 6-8, 9-12
- **Big ideas:** ...
- **Author / source:** ...
- **License:** CC BY-NC-SA 4.0 (ours) or the external resource's own license
- **Why it's useful:** One or two sentences.
```
