# Inbox

A drop zone for existing materials before they are sorted into a region. Put files here as they
are, then record them in the inventory below.

## How to add materials

- **PDFs and slide decks:** put them in a subfolder named for the topic, e.g.,
  `inbox/data-science/`. Files over ~50 MB should be linked rather than committed (see
  [decisions](../docs/decisions.md)).
- **Google Slides, Docs, and other web links:** add a row to the inventory with the URL.
- **GitHub repos:** add a row with the repo URL.

## Inventory

| Item | Type | Topic / Area | Grade band | Status | Notes |
|---|---|---|---|---|---|
| | | | | new | |

Status values: `new` → `reviewed` → `converted` (moved into an area) or `link-only`.
