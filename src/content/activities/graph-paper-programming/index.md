## What you'll do

A robot can't guess what you mean. It only does exactly what its program says. In this activity
you and your group are the programmers: you write a program, in symbols, that tells a robot how to
draw a picture on a grid. Then you swap programs with another group and become their robot.

## The symbols

| Symbol | What the robot does |
| --- | --- |
| → | Move one square right |
| ← | Move one square left |
| ↑ | Move one square up |
| ↓ | Move one square down |
| ■ | Fill in the square it's on |

The robot always starts on the top-left square.

## How it works

1. **Choose a picture** with your group, without letting the other group see it.
2. **Plan the steps.** Talk through every step the robot needs. That list of steps is an
   **algorithm**.
3. **Write the program.** Turn the algorithm into symbols on the program sheet. Now it's a
   **program**.
4. **Swap.** Give your program to another group. Their robot follows it exactly on a blank grid,
   while you follow theirs.
5. **Check.** Compare each drawing with its picture. If one is wrong, find the **bug** together and
   fix it.

## Challenges

- Program a picture on a bigger grid.
- Design your own picture, then write its program.
- Make a program shorter by writing a number before a symbol: 3→ means "move right 3 times."

## Afterward

- Was it harder to write the program or to follow it? Why?
- Did two groups write different programs for the same picture? Were both right?
- What would happen if the robot started in a different square?
- What other robots could you program if the symbols meant something else?
