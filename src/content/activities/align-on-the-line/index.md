## What you'll do

AI can help with almost any assignment. It can explain an idea, check your spelling, or write the
whole thing for you. Some of those uses help you learn, and some do the learning for you. In this
activity you'll decide where the line is for one assignment, find out where other people put it,
and agree on a line as a class.

## The line

Every use goes in one of five places:

| | Place on the line |
| --- | --- |
| ✓✓ | Totally fine |
| ✓ | Mostly OK |
| ? | Not really sure |
| ! | Feels sketchy |
| ✕ | Crosses a line |

## How it works

1. **Brainstorm.** List every way someone *could* use AI on the assignment. Don't judge them yet.
   Or start with one of the card sets: a persuasive essay or a coding project.
2. **Map on your own.** Write each use in the column where you think it belongs.
3. **Compare with a partner.** Find the uses you placed differently and explain why.
4. **Align as a class.** Sort the cards together on the class poster and decide where the line goes.
5. **Keep the map.** Post it where everyone can see it, and come back to it when you're not sure.

## Afterward

- Which use did people disagree about most? Why?
- Did hearing someone else's reasons move any of your uses?
- Would your line be in the same place for a different class or assignment?
- What's the difference between AI helping you learn and AI doing the learning for you?
