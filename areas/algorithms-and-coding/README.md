# Algorithms and Coding

> A region of Computation Quests. Status: **not started**. Every activity is unplugged:
> students use no technology.

## Overview

Students design, write, test, and debug programs on paper, then run them by hand, from first sequences and loops to complete projects.

## Topics (draft)

- Sequences, loops, and conditionals
- Variables and data types
- Functions
- Testing and debugging
- Program design

## Activity ideas

Unplugged ideas, one or more per topic, to write up as activities.

| Topic | Idea | What students do |
|---|---|---|
| Sequences, loops, and conditionals | **Grid Robots** | On a floor or paper grid, students program a classmate with arrow cards, then add repeat and if cards to shorten their programs. |
| Variables and data types | **Box Tracing** | Labeled envelopes stand for variables; students trace a paper program step by step, swapping the slips inside. |
| Functions | **Dance Functions** | The class names a sequence of moves, then calls it by name, with inputs, to build a longer routine. |
| Testing and debugging | **Bug Hunt** | Pairs run printed programs that contain planted bugs, write test cases, and fix the steps. |
| Program design | **Paper Prototype** | Groups design an app on index cards, one screen per card; classmates test it by tapping the cards while a designer swaps them. |
