# Computational Thinking

> A region of Computation Quests. It is the **starting point** of the map. Status: **not started**. Every activity is unplugged:
> students use no technology.

## Overview

The starting point. Students learn to break problems into parts, recognize patterns, focus on what matters, and describe solutions as clear steps.

## Topics (draft)

- Decomposition
- Pattern recognition
- Abstraction
- Algorithmic thinking

## Activity ideas

Unplugged ideas, one or more per topic, to write up as activities.

| Topic | Idea | What students do |
|---|---|---|
| Decomposition | **Break It Down** | Groups split a big job, such as running a school event, into smaller and smaller tasks on sticky notes, building a task tree on the wall. |
| Pattern recognition | **Guess My Rule** | One student secretly picks a rule for sorting picture cards; the class tests cards to discover it. |
| Abstraction | **Map Maker** | Students draw a map of the school for a new student, then compare which details each map kept and which it dropped, as a transit map does. |
| Algorithmic thinking | **Human Robot** | Partners write exact steps for a task such as folding a paper airplane; a classmate follows them literally, and the class sees where the steps fell short. |
